# Kseniia review migration to current CUC IDs (draft)

Source: [DT-UCPH/cuc PR #39](https://github.com/DT-UCPH/cuc/pull/39), branch `review/1.6-Kseniia`, commit `365f7fc7c8dbbaddb45ad5e4e21bf4742b195344`.

Target: upstream `main` commit `ab7e166ec568019bc0e3e98c3bc95edc0b770984` and `auto_parsing/0.2.7`.

This migration is a **draft for expert review**, not an approval of morphological analyses.

## Conservative transfer policy

- Group all TSV alternatives by token ID and by KTU verse (heading), retaining all analysis alternatives.
- Match review tokens and current automatic-parser tokens in order *within their verse*, using **exact surface equality** and an optimal longest common subsequence (LCS) alignment.
- Transfer annotations only when a surface occurs in a **unique review-to-current pairing among all optimal LCS alignments** and every alternative row for the old token has the same surface.
- Give transferred rows the current automatic-parser token ID and surface, preserving all reviewed analyses, sign spans (KTU 1.1), and comments.
- For every current token that cannot be safely matched, retain its current automatic-parser alternatives with an explicit `PENDING_TOKENIZATION_REVIEW` comment. Such rows **are not reviewed**.
- Preserve all unmatched expert-review rows verbatim in the reconciliation exception TSV, including readings and grammatical alternatives, instead of guessing how to attach them to changed tokens.
- Do not modify PR #39's original files.
